# Cómo contribuir

1. Crea una rama desde `main`: `feature/nombre-del-cambio`.
2. Realiza cambios pequeños y verificables.
3. Ejecuta `npm run validate`.
4. Escribe un commit que explique el resultado, por ejemplo: `test: agrega casos para prioridades inválidas`.
5. Publica la rama y abre un pull request.
6. Solicita la revisión del otro integrante de Bemati Studio.
7. Adjunta evidencia de las pruebas y explica cualquier cambio de infraestructura.

No subas claves, tokens, archivos `.env` ni `frontend/config.js`.
